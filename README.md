# Addofilms Website

This repository contains the source code for the Addofilms website.

## Overview

A simple landing page / website project for Addofilms.

## Getting Started

### Prerequisites

- Node.js (if this project uses a JavaScript framework)
- npm or yarn
- A modern browser

### Installation

```bash
git clone https://github.com/Addofilms/website.git
cd website
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in the terminal (typically http://localhost:3000).
